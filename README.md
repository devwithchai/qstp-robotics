# QSTP Robotics

This repository documents my learning and implementation work from robotics-focused Quark Summer Technical Projects (QSTP) conducted by students of BITS Pilani, K. K. Birla Goa Campus.

I participated in the Project Kratos Autonomous Subsystem QSTP in 2024, 2025, and 2026. I could not complete every assignment within the original submission deadlines, so this repository preserves my earlier work and documents the remaining projects as I revisit them with a better understanding of the concepts involved.

## Programs

| Program | Edition | Repository status |
|---|---:|---|
| Project Kratos - Autonomous Subsystem QSTP | 2024 | Partial work preserved |
| Project Kratos - Autonomous Subsystem QSTP | 2025 | To be revisited |
| Project Kratos - Autonomous Subsystem QSTP | 2026 | To be revisited |
| Introduction to ROS2 | 2026 | To be organized |

The yearly Kratos editions share core topics such as ROS, TurtleBot simulation, obstacle avoidance, actions, navigation, and computer vision. However, their assignments are not identical: each edition uses a different progression and adds new project work.
